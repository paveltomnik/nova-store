# NOVA Wear

Демо-магазин одежды для гайда BrainAid «Codex: команды и фишки». Собирается Codex по коротким командам.

Откройте `index.html` в браузере. Для запуска достаточно файлов из этого репозитория.

В каталоге 48 товарных позиций в разделах «Женское», «Мужское» и «Аксессуары». Поиск учитывает название, категорию и цвет. В фильтрах можно выбрать категорию, размер, цвет и диапазон цен. У каждой позиции есть собственный адрес и фотография.

Корзина и избранное сохраняются при доступном локальном хранилище браузера. Промокод `NOVA10` даёт скидку 10% на товары. Стоимость доставки зависит от города и способа получения. Пункт выдачи бесплатный при покупке от 10 000 ₽ после скидок.

Для демо-заказа используйте вымышленные данные. Подтверждение появляется на странице, оплата и доставка имитируются.
