# NOVA Wear

Демо-магазин одежды для гайда BrainAid «Codex: команды и фишки». Собирается Codex по коротким командам.

Откройте `index.html` в браузере. Для запуска достаточно файлов из этого репозитория.

В каталоге восемь товаров с фильтрами по категории, размеру и цене. Корзина сохраняется в браузере при доступном локальном хранилище. При оформлении можно указать вымышленные данные. Подтверждение заказа появляется на странице.
